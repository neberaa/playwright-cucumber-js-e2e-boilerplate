# Playwright + Cucumber.js E2E test starter

A JavaScript end-to-end testing starter that combines [Microsoft Playwright](https://playwright.dev/) with [Cucumber.js](https://github.com/cucumber/cucumber-js) and a Page Object approach.

The project is intended as a starting point for browser-based acceptance tests across Chromium, Firefox and WebKit.

## Stack

- **Playwright** — browser automation
- **Cucumber.js 7** — Gherkin feature files and step definitions
- **Chai** — assertions
- **Cucumber HTML Reporter** — HTML test report
- **JavaScript** — test implementation

## Getting started

### Requirements

- Node.js
- npm

Install dependencies:

```bash
npm install
```

## Run the tests

```bash
npm test
```

The configured test command runs Cucumber.js with the project support code and step definitions. It writes an HTML report to:

```text
reports/cucumber_report.html
```

The formatter configuration also includes the Cucumber summary and pretty formatter. The report directory is generated by the reporter when the test run completes.

## Project layout

The framework is organised around Gherkin features, step definitions and shared Playwright setup. Page Object patterns keep browser interactions separate from scenario intent.

When extending the starter, keep:
- scenario language in `features/`
- reusable browser interactions in page objects
- step glue in the step-definition directory
- shared browser and Cucumber configuration in the support files

## Notes

This repository uses the Cucumber.js 7 generation and an early Playwright dependency range. Review and update dependencies before adopting it in a new production test suite, and verify the test command against your current Node.js version.
